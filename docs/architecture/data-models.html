Database Schema & Data Models

Full specification of SQLite tables in workbench.db, relational foreign key constraints, column data types, and indexing rules.

1. Database Invariants & Pragma Rules

The database layer is defined in database.py:30-165. Every connection opened by the server executes: 

PRAGMA foreign_keys = ON;
PRAGMA journal_mode = WAL;

Foreign Key Cascades: Deleting a study (campaigns) or test suite automatically cascades to delete associated evaluations, defect tags, and rater scores without leaving orphaned records in the database.

2. Table: campaigns (Active Evaluation Studies)

Stores high-level evaluation studies, linking a prompt suite, scoring rubric, and UI component layout.

Column Name Type Key Default / Null Physical Responsibility & Relationships
id TEXT PK NOT NULL Unique campaign identifier (e.g. camp-dev23-4models).
project_id TEXT FK NOT NULL References projects(id) ON DELETE CASCADE.
name TEXT — NOT NULL Human-readable study title (e.g. Khmer Natural Voice Benchmark).
suite_id TEXT FK NOT NULL References test_suites(id) ON DELETE CASCADE.
rubric_id TEXT FK NOT NULL References rubrics(id) ON DELETE CASCADE.
ui_config_json TEXT — NULL JSON payload defining Step 3 canvas blocks, speeds, blind gating, and filters.
is_active INTEGER — 1 Binary status flag (1 = Active for raters, 0 = Paused/Closed).
created_at TIMESTAMP — CURRENT_TIMESTAMP UTC timestamp when study was created.

3. Table: evaluations (Rater Score Records)

Stores individual evaluator submissions for each test item and speech model candidate.

Column Name Type Key Default / Null Physical Responsibility & Relationships
id TEXT PK NOT NULL Unique evaluation identifier (e.g. eval-1795451589-9812).
campaign_id TEXT FK IDX NOT NULL References campaigns(id) ON DELETE CASCADE.
rater_id TEXT FK IDX NOT NULL References raters(id) ON DELETE CASCADE.
item_id TEXT FK IDX NOT NULL References test_items(id) ON DELETE CASCADE.
model_id TEXT FK IDX NOT NULL References models(id) ON DELETE CASCADE.
scores_json TEXT — NOT NULL JSON map of rubric dimensions to integer scores (e.g. {"naturalness":5}).
blind_transcript TEXT — NULL Text submitted by listener reporting perceived differences from prompt.
duration_seconds REAL — NULL Time in seconds the evaluator spent listening and rating this item.

4. Table: defect_tags (Acoustic Glitch Annotations)

Stores fine-grained timestamped defect regions and flagged word tokens.

Column Name Type Key Default / Null Physical Responsibility & Relationships
id TEXT PK NOT NULL Unique defect tag identifier formatted as dt-{ts}-{idx}-{uuid4} to prevent primary key collisions on batch submission (REV-001).
evaluation_id TEXT FK IDX NOT NULL References evaluations(id) ON DELETE CASCADE.
error_code TEXT — NOT NULL Taxonomy code: MISPRON, NOISE, UNNAT_PAUSE, ROBOTIC, PITCH, OTHER.
word_text TEXT — NOT NULL Khmer word token or acoustic region label.
time_start_ms REAL — NULL Start timestamp in milliseconds on the waveform.
time_end_ms REAL — NULL End timestamp in milliseconds on the waveform.

5. Supporting Metadata Tables

Table Name Primary Key Core Stored Data Source Location
projects id (TEXT) Parent workspace and language metadata (e.g. Khmer language km). database.py:31
test_suites id (TEXT) Named prompt groups containing audio and transcript items. database.py:39
test_items id (TEXT) Individual test sentences, phonetic IPA targets, and audio filenames. database.py:47
models id (TEXT) Speech model candidates (VITS, Kokoro, FastSpeech2, Ground Truth). database.py:65
rubrics id (TEXT) Evaluation scale criteria (ACR 1-5 Likert scales, dimensions JSON). database.py:81
taxonomies id (TEXT) Standardized defect categories with English and Khmer definitions. database.py:92
raters id (TEXT) Unique evaluator names, pseudonyms, and rater roles. database.py:117
admins id (TEXT) Salted and hashed administrator passwords for study management. database.py:150
