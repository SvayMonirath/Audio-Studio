2. Detailed Subsystem Responsibilities

Tier 1: Client Applications & DSP

The frontend runs completely in the user's browser without external CDNs. It uses the Web Audio API and HTML5 Canvas to create rich audio inspection interfaces:

  • Buffer Decoding: Audio files are fetched and decoded into 32-bit floating point audio buffers in memory.
  • Telephone Simulation: When toggled on, audio routes through a Biquad bandpass filter (highpass at 300 Hz, lowpass at 3400 Hz) to simulate telephony call center acoustics.
  • Rater Waveform Deck: 76px canvas rendering vertical peak bars, active playheads, and real-time drag-to-tag defect highlight overlays at 60 frames per second. Features local draft caching per study/rater with explicit reset.
  • Admin DSP Waveform Inspector: Dedicated modal (#modal-inspect-evaluation) with interactive defect span click-to-seek, 1.0x / 0.8x playback speed toggling, and synchronized audio playback.
  • Rater Coverage Modal: Per-evaluator item checklist (#modal-rater-coverage) filtering by All, Evaluated, and Not Evaluated items.

Tier 2: Ingress & Edge Network

Provides a secure bridge between mobile evaluators on the internet and the local host computer:

  • Automatic HTTPS: Terminating SSL/TLS at Cloudflare ensures mobile browsers allow Web Audio playback without security restrictions.
  • Outbound Connection: cloudflared establishes an outbound TCP/TLS session on port 7844. No incoming firewall ports or router NAT settings are opened.
  • Zero Billing Risk: Cloudflare Tunnel free tier has no data transfer quotas, eliminating overage charges.

Tier 3: Core Application Engine

run_server.py acts as the single backend process:

  • Multi-Threaded Server: Built on http.server.ThreadingHTTPServer. Each incoming request spawns a lightweight thread, allowing multiple evaluators to stream audio simultaneously.
  • HTTP Range Handler: Implements RFC 7233 byte-range parsing. Requests with Range: bytes=0-1024 return HTTP 206 with exact byte boundaries.
  • Admin Authorization: Verifies X-Admin-PIN header on all state mutations, while keeping public evaluation submission open for friction-free rating.

Tier 4: Storage & Persistence

All data is saved locally on the host computer's hard drive:

  • Relational Integrity: workbench.db operates with PRAGMA foreign_keys = ON; to prevent orphaned evaluation records or missing item references.
  • Safe Audio Directories: Uploaded audio files are validated and stored under public/uploads/ and audio/uploads/ with unique timestamps to prevent file overwrites.
